# Mediafundament website

Een statische, responsive website voor GitHub Pages.

## Bestanden
- `index.html` — complete website, inclusief CSS en JavaScript
- `assets/mediafundament-logo.png` — transparante versie van het aangeleverde logo
- `assets/hero.jpg` — aangeleverde voorbeeldafbeelding

## GitHub Pages
1. Maak een nieuwe GitHub repository.
2. Upload `index.html` en de map `assets`.
3. Ga naar **Settings → Pages**.
4. Kies **Deploy from a branch** en selecteer `main` / root.
5. Open de URL die GitHub daarna geeft.

## Aanpassen
Zoek in `index.html` naar teksten zoals `hello@mediafundament.nl`, diensten, cases en contactgegevens en vervang deze met de echte gegevens.

De layout is bewust zonder frameworks of externe dependencies gebouwd, zodat hij direct op GitHub Pages werkt.
